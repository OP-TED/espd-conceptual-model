# espd-conceptual-model
Conceptual model and source data for external codelists for ESPD-EDM

## Contents

- `conceptual-model/` - the Enterprise Architect model (source of truth for the ESPD structure)
- `enrichment/` - JSON enrichment of the model (semantic ids, instance bindings, value types, UBL bindings, roles); see [enrichment/README.md](enrichment/README.md)
- `documentation-integration/` - assets for publishing the EA model as HTML on the TED documentation site
- `external-sources/`, `mock-ups/` - reference material
